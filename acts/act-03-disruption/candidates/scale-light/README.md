# act-03-disruption · 候选 `scale-light`（同价拆箱 · 5 拍）

- **所属幕次**：[act-03-disruption](../../README.md)
- **状态**：当前主选（第三幕唯一候选）
- **设计出发点**：回到剧本 M04 的原意——「消费端共识算术」。一幕只有一个主角（天平 + 两根 ¥100 价值柱），不再重复第二幕已讲过的「围墙 / 绕行 / 崩塌」。每拍屏幕上只有一句标题和一句补充，完整口播在讲稿（`N`）里。
- **核心 3D 实体**：
  1. 顶置托盘精密天平：两端同价时保持水平，换了裁判就翻转；
  2. 两根 ¥100 价值柱（1 mm = ¥1，四角立柱 + 顶部价签「售价 ¥100」）：
     - A：用料 ¥20（琥珀块）｜广告 ¥30（黑金漆块）｜利润 ¥50；
     - B：用料 ¥50（琥珀块）｜利润 ¥50；
     - 20–50 mm 这一段对齐：A 放的是广告，B 放的是用料；
  3. 包装套：A 黑金「人气爆款」带广告光环，B 素白；用水平裁切面做「扫描去包装」；
  4. 裁判徽章：正面「人眼」，翻面「AI 第二大脑」；
  5. 第 5 拍的「B · 真实用料档案」数据卡，由金色光丝把 AI 与 B 接起来。
