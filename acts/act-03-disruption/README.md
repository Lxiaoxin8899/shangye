# act-03-disruption · 第三幕任务书（消费端共识算术：同样 ¥100，你选哪一个？）

## 一、任务书（对应剧本 M04，纯商业逻辑，零 MCP 硬广）

- **核心命题**：用一道观众自己能答出来的算术题建立共识——同样卖 ¥100，A 用料 ¥20、广告 ¥30；B 用料 ¥50、广告 ¥0。过去 30 年人眼来选，看见的是广告，A 赢；AI 成为第二大脑后，它只看用料，选 B。**前提是 B 的真实用料必须对 AI 可见**，由此引出第四幕的材料数据卡。
- **边界**：「展示 · 入口 · 心智被推翻」「AI 绕过围墙」属于第二幕（M02–M03），本幕不再重复；本幕不提 MCP。
- **视觉基调**：延续 **浅调 · 瑞士精密画廊**（`#F1EFE9` 暖白展台 + 深钛灰 / 拉丝银 / 香槟金 + 琥珀色用料块）。一幕一主角：精密天平 + 两根 ¥100 价值柱（1 mm = ¥1）。
- **五拍节奏（Beats）**：
  1. `Beat 0`（M04-A · 提问）：两件包装好的同价产品放上天平，天平水平——「同样 ¥100，你选哪一个？」
  2. `Beat 1`（M04-B · 拆开）：扫描去掉包装，露出价值柱；20–50 mm 同位带金框提示「同样 ¥30，A 买了广告，B 放进了产品」；两家利润同为 ¥50；
  3. `Beat 2`（M04-C · 人眼）：包装合上，「人眼」徽章升起；A 被聚光、B 隐没，天平倒向 A；
  4. `Beat 3`（M04-D · AI）：徽章翻面为「AI 第二大脑」，再次扫描看穿包装；广告块失去分量，天平翻向 B（用料 2.5×）；
  5. `Beat 4`（M04-E · 前提）：「B · 真实用料档案」数据卡升起，光丝连通 AI 与 B——「B 的真实用料，AI 必须看得见」。
- **转场契约**：`enterWith: 'fade'`，`transitionDur: 0.85`。
