# act-07-commerce-platform · 第七幕任务书（一次对接，多方拉通：从一句泛需求到待确认订单）

## 一、任务书（对应剧本 M07 · 平台终态：全球 AI 商业平台）

- **本幕承担什么**：第六幕证明 MCP「能接进来」，第七幕证明接进来之后 **B2B 真能把事办成**。把观众对项目的认知从「行业查询工具」抬升为「B2B 交易平台」，并为第八幕的盈利模式铺路。
- **核心命题**：
  1. **问题可以很泛**：第四、六幕回答的是一个材料的精准问题；本幕只说一句「我需要开发一款一次性电子烟」，得到的是一整款产品的组合方案。
  2. **一次对接，多方拉通**：一个客户原本要逐家对接壳料、电池、烟油、代工四家企业；通过 MCP，**只对接一次就能同时对接多家**。MCP 在中间负责 **查询 · 确认 · 传递任务**。协商是方式，拉通是目的。
  3. **Agent 谈完，人做判断**：交到人手里时，大部分问题已经确认，人只需要判断和确认。
- **MCP 在中间的三件事**：
  - `查询`：基于全链知识，按需求拆解并找到真实可用的企业；
  - `确认`：核对工厂真实产能、资质、交付记录与排期（工厂 Agent 报交期时读取自身 ERP / MES 的真实排期，而非口头承诺）；
  - `传递任务`：把客户需求与条款按统一格式同时分发给多家工厂 Agent，并回收结果。
- **工厂 Agent 从哪来**：平台提供标准接入方式，我们协助部署（承接企业 AI 部署业务）。本幕只轻带一句，不展开。
- **边界**：
  - 不重复第六幕的「插上就能用」与单点查询演示，不再画六环；
  - 不讲价格体系与收费方式（留给第八幕 M08）；
  - 不说「全自动无人交易」，姿态是「Agent 去谈，人来拍板」（呼应第九幕数据安全：机密与决定权在企业手里）；
  - ERP / MES 不单独成拍，作为第 3 拍工厂 Agent 报交期的细节出现；
  - 画面上不堆术语（BOM、三单匹配等不上屏）。
- **数字口径**：画面上所有价格、账期、交期、起订量等数字统一标注「示例」。

## 二、五拍节奏（Beats 0–4，页面代号 M07-A…E）

| 节拍 | 代号 | 画面与核心动作 | 前台一句话 |
| :--- | :--- | :--- | :--- |
| Beat 0 | `M07-A` | 客户提出一句泛需求：**「我需要开发一款一次性电子烟」**，旁附三个约束：`欧美市场 · 首单 10 万支 · 西瓜口味`（呼应第四幕） | 问题可以很泛 |
| Beat 1 | `M07-B` | 需求胶囊进入 MCP，被拆成四条线：**壳料 · 电池 · 烟油 · 代工厂**；每条线从大量候选中收敛出几家真实可用的企业 | 不给名单，直接找到对的企业 |
| Beat 2 | `M07-C` | 生成 **组合方案 1 / 2 / 3** 三张方案卡，每张列出：合作方式 · 账期 · 交付时间 · 最小起订量。三套方案各有侧重：①交期最快 ②起订量最低 ③账期与成本最优 | 一句话，换回三套可以直接选的方案 |
| Beat 3 | `M07-D` | 客户选定方案并「直接下单」。先闪现旧方式：客户与四家企业逐一连线、重复沟通的乱线；随即收拢为 **客户 Agent → MCP → 四家工厂 Agent** 的星形结构。四路同时就 **需求 · 交付 · 条款** 自动协商，条目逐条变绿「已确认」；工厂 Agent 报交期时可见其读取自身排期（ERP / MES）。角落轻标：`工厂 Agent · 标准接入 · 协助部署` | 一次对接，多方拉通 |
| Beat 4 | `M07-E` | 收束为一张确认单：**「18 项已确认 · 2 项待您判断」**（例：交期提前 5 天是否接受加价 / 账期 30 天还是 45 天），下方一个 `[确认下单]` | Agent 谈完，人只负责判断和确认 |

- **时长估算**：五拍合计约 50–60 秒，具体 `dur / hold` 在候选制作时定。
- **转场契约**：`enterWith: 'fade'`，`transitionDur: 0.85`。
- **交互约定**：纯前后翻拍自动演出（键盘 `←`/`→`、轻点/横滑翻拍、`N` 讲稿、`P` 演讲者副屏）。

## 三、演讲者备注（草稿）

1. **【M07-A · 一句泛需求】** 前面我们看到，MCP 能精准回答一支香精的问题。但真实的 B2B 需求往往很泛——比如一个欧美客户只说一句：我需要开发一款一次性电子烟，首单 10 万支，西瓜口味。
2. **【M07-B · 拆解寻源】** MCP 会把这句话拆开：壳料、电池、烟油、代工厂，每一条线都在全链知识里找到真实可用、能对得上的企业，而不是丢给客户一份名单。
3. **【M07-C · 组合方案】** 然后直接给出三套组合方案：交期最快的、起订量最低的、账期和成本最优的。每套方案写清合作方式、账期、交付时间和最小起订量。
4. **【M07-D · 一次对接，多方拉通】** 选定之后直接下单。过去，客户要一家一家去对接、反复沟通；现在客户只对接一次，MCP 在中间负责查询、确认和传递任务，客户的 Agent 和四家工厂的 Agent 同时把需求、交付和条款谈下来。工厂报的交期来自它自己系统里的真实排期。工厂的 Agent 通过平台的标准方式接入，我们可以协助部署。
5. **【M07-E · 交给人】** 等这件事交到人手里的时候，大部分问题已经确认好了——18 项已确认，只剩 2 项需要您判断。Agent 去谈，人来拍板。
