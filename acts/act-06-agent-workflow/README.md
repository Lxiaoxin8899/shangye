# act-06-agent-workflow · 第六幕任务书（v4 悬浮空间电影镜头版）

## 一、镜头语言与空间革新

- **彻底告别地面、底座与桌面俯拍**：构建无边界暖白柔光渐变穹顶（越远越亮融进柔光）+ 悬浮空间微尘，所有物体均反重力悬浮在空气中，靠倒角金属高光与金边轮廓光立住体量。
- **真实实时光学景深（16-tap Vogel Disk Bokeh DoF）+ 动态变焦（FOV 18.5° ↔ 36°）**：自带场景级 `DepthTexture` 散景后处理通道，支持前景虚化线缆、微距浅景深、星系轮播实时移焦与中层滴液特写；2D 标题层永远叠在 DoF 之后保持锐利。
- **单主角贯穿 4 拍，全片 10 个电影运镜段落**：
  1. **Beat 0 · 插上就能用**：`0–1.5s` 微距特写（`18.5°` + 前景虚化线缆 + Claude 插头咔哒插入溅起金色火花）→ `1.5–4.0s` 沿线急速后拉带出另 5 根三维空中弧线插入 → `4.0–8.0s` 略仰视中景定格（6 根光纤向画外三维放射、芯片呼吸）。
  2. **Beat 1 · 一道题看它怎么想**：`0–2.5s` 跟随提问胶囊飞向芯片 → `2.5–4.5s` 裂成 4 枚金属令牌落入芯片并**俯冲穿越金色电路通道** → `4.5–9.5s` 持续穿越三维纵深悬浮样品/空心壳厂云阵，4 道香槟金光幕迎面扫过、空心壳厂在镜头前慢动作炸裂 → `9.5–13s` 冲出光幕焦点锁定中央唯独悬浮的西瓜香精瓶与源头 B 厂 + 唯一 3 行白卡 + 回传金光。
  3. **Beat 2 · 全链六环**：大远景（`34.5°`）围绕中心 MCP 恒星环绕约 90°；5 件高精实物在三维不同高度与纵深像行星般自转，倾斜香槟金合规光环斜穿星系；每 1.65s 自动将光学焦点移至活跃行星并双向发射问答光束。
  4. **Beat 3 · 底座是怎么炼成的**：`0–2.0s` 沉到芯片正下方大角度仰拍逆光剪影（金边轮廓 + 背后强柔光晕）→ `2.0–8.1s` 垂直三层空中爆炸展开并边升边绕 120°，掠过底层游标卡尺 → 在**中层 CNC 自动化调香放慢推近特写（`21.5°`）**展示琥珀液滴坠落进旋转瓶与跳动的绿色 GC-MS 波峰 → `8.1–10.5s` 三层合拢并拉回与 Beat 0 结尾呼应的略仰视中景。
