# act-05-customer-discovery · 第五幕任务书（客户如何找到我 · MCP 精准回答 · 全球展会双面展台）

## 一、核心命题（承接第四幕「我需要……」）

- **视角反转**：商家总在问「怎么找到客户」，但 AI 时代真正决定胜负的是 **「客户如何找到我」**。
- **海外客户困境**：从海外视角回望中国/深圳供应地——品牌多、工厂多、材料多、真真假假；传统搜索与黄页只能吐出一份 **3,842 家企业名单**，如何选择、怎么评估、怎么对比分析，完全无从下手。
- **数据库 MCP 价值**：不给企业名单，而是给出 **精准的回答**——瞬间收敛至 **Top 3 真实认证工厂同维对比**，并锁定最优方案展开完整档案（具体产品、核心参数、合规规格、真实工厂产能/MOQ/交期/报价）。
- **全球展会落地闭环**：电子烟行业每年有大量全球展会，设计一座极具辨识度的 **「AI 渠道库 · 双面展台」**：
  - **面对供应商一面**：`扫码加入 AI 渠道库 · 马上连接全球客户`
  - **面对海外买家一面**：`扫码加入 AI 渠道库 · 马上连接真实工厂`

## 二、视觉与空间约定

- **视觉主风格**：严格延续前四幕 **浅调 · 瑞士空间悬浮画廊**（`#F1EFE9` 暖白无影展台 + 负补光高对比棚拍 HDRI + 哑光深钛灰 / 拉丝银铝 / 厚壁透明件 / 香槟琥珀金点睛）。
- **坐标与单位**：米制坐标（`1 unit = 1 m`），地坪位于 `y = 0`，所有落地展台与底座贴地无穿插。
- **转场契约**：`enterWith: 'fade'`，`transitionDur: 0.85`。
- **交互约定**：纯前后翻拍自动演出（支持键盘 `←`/`→`、轻点/横滑翻拍、`N` 讲稿、`P` 演讲者副屏及轻微鼠标视差）。
