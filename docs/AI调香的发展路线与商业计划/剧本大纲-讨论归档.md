# AI调香的发展路线与商业计划 · 讨论大纲归档（v2 主线）

> 归档日期：2026-11-23。此稿记录首轮讨论成型后的四篇逻辑骨架；完整逐字配音剧本见 [剧本.md](剧本.md)。

## 四篇演进主轴

1. **第一篇 · 现实起点**：面向电子烟行业的 **AI 应用调香**（侧重配方与应用，面对多厂家香精、单体、设备、棉芯/陶瓷芯发热体、功率、法规等多维复杂耦合）+ **电子烟自动化调香设备**。
2. **第二篇 · 实践洞见**：AI/Agent 技术不是绝对壁垒；企业 Agent 的困境集中在**数据治理**与**业务理解**；我们的优势是对电子烟行业有充分理解，能将 **Agent + 数据治理 + 业务理解**深度结合，从应用调香启动企业 AI 流程化、全面 AI 化并延伸至**企业 AI 部署**；真正的壁垒是**全供应链垂直知识的整理**（单体材料参数、香精评价描述、香精 GC-MS 数据、设备参数功率、发热体型号参数、电池、电路方案板、壳料、书籍论文、全供应链所有知识；不论怎么设计怎么做都要用；苦活累活即壁垒）。
3. **第三篇 · 发展路线**：
   - 建立**行业知识 MCP**（一库两用：支撑企业定制 Agent 系统涵盖调香/采购/研发；赋能 `WorkBuddy`、`豆包工作`、`QoderWork` 等通用型 AI 工具解决公开检索无法获得的行业查找/调研/采购数据来源）；
   - 供应链首批切入**香精、发热体、电池、壳料、方案板**；针对早期香精厂愿意支持但缺复杂表现力评估、未讲清自身价值的问题，提供**统一评价标准 + 协助评估**，对标 **XX 杂志、XXX 媒体** 等商业期刊与行业媒体建立**AI 时代的曝光渠道**；早期以我们主动推进为主，随客户端使用比例提升占据主动权，供应商更有动力主动提供资料；
   - 严守**数据安全红线**（数据安全是项目发展的核心与必要性；只提供明确开放的数据及法律框架下允许的信息；绝不涉及用户商业机密与研发技术；专注整理管理难度大的公开或需挖掘信息）；
   - 演进为**AI 时代的商业平台**（A 企业找料匹配 → 价格、交期、账期、条件由 Agent 间直接协商；接入 ERP/MES 实现缺料分析、Agent 下单物料、核查账单等）。
4. **第四篇 · 商业计划与最终目标**：总体目标建立 **AI 时代的知识信息与商业平台**；分阶段盈利（MCP 按次如 0.1 元/次或订阅制，供需双身份享优惠套餐，并行企业部署与曝光服务；具一定市场占有率后收费准入，供需双向付费降低双方成本）；最终目标**成为行业的基础设施**。
