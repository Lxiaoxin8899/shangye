## 基础验证

- 在中文目标路径使用锁文件独立执行 `npm ci --offline --no-audit --no-fund`，随后完成 `npm run check`、`npm run build` 和 `npm run build:singlefile`。环境为 Node.js 24.20.0、npm 11.19.0。
- Chromium 系浏览器 152.0.7977.64 经 ANGLE / SwiftShader 实际运行 WebGL2。`npm run verify` 检查工具首页、两个总装视图、模型检视台、双 iframe 和拉帘位置。移出开发依赖后，使用 Python 静态服务器再次打开多入口版本。在浏览器离线模式中用 `file://` 打开单文件播放器，清单与多入口版本一致。
- 截帧尺寸为 960 × 540。画面分别显示同一校准块的 PBR 与线框、100 mm 尺寸字形与选框、白棚中的法线着色。[分屏静帧](../outputs/master/acceptance/scene-1.png) · [尺寸静帧](../outputs/master/acceptance/scene-2.png) · [法线静帧](../outputs/master/acceptance/inspector.png)
