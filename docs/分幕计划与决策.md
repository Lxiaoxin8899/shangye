## 二、跨幕通用约定

- **视觉**：第六幕起统一「悬浮空间 + 实时景深」（零地面、暖白柔光穹顶、悬浮微尘）。新幕从上一幕的 `floating-light` 候选复制 shaders / materials / props / overlay 框架。
- **清晰度**：2D 版面实现 `renderOverlay`，在调色之后叠加，并随渲染分辨率重绘；3D 标签用「深度测试永远通过 + 写入深度」，让景深按真实距离判断；景深目标 4× MSAA。
- **一幕一主角**：每一拍只留这一拍的主角，其余元素退场或压暗；用户嫌「画面乱」时，先删同屏元素。
- **具象优先**：不用抽象符号（球形光环、插头线缆都被否过），改用观众一眼认得的实物与前后状态变化。客户 Agent 用「对话入口」面板。
- **配色语义**：客户 / 问题蓝，MCP 香槟金，企业 / 工厂 / 合法来源绿，红色只给红线与被拒的东西，第三幕广告块琥珀橙。
- **流程**：先对齐计划再动手；提交、合并、推送都等用户明确说了再做。
