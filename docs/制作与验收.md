# 三维场景制作与验收

## 从任务书到总装

1. **定义单元。** 在 `acts/<单元>/README.md` 记录要展示的对象、信息来源、物理单位、观察距离、各拍时长、交互和进出镜约定。尺寸尚未确认时先标出来源和待测量项。
2. **制作候选。** `npm run new:candidate -- unit-01 variant-a` 会创建可以打开的独立页面。每个候选的 `models/`、`textures/` 和 `shaders/` 由该候选自己维护。共用能力从 `core/` 导入。记录建模脚本、素材来源、关键参数、测量结果和预览地址。
3. **检查模型（A）。** 用检视台看主体本身，记录包围盒、底面与多角度静帧。
4. **检查单元（B）并比较候选（C）。** 使用相同视口、同一节拍、同一指针位置和镜头检查候选。对比台的两个播放器各自独立。固定采样可在两侧都使用 `?headless#<场景ID>-<拍号>`。记录选定版本、日期和取舍理由。
5. **登记总装（D）。** 在 [清单](../master/manifest.js) 导入选定候选的 `scene.js` 默认导出，按播放顺序返回数组。替换默认测试视图后重新构建并运行验收。动态效果优先在浏览器查看，静帧、模型和最终交付分别验收。

## 模型质量

- 使用米制坐标，`1 unit = 1 m`。记录底面中心或安装基准。检视台按毫米报告世界空间包围盒和最小 Y，默认贴地阈值为 0.5 mm。包围盒只能判定最低点，对零件间穿插和安装面接触还需逐角观察。
- 在最近的镜头距离观察转角、接缝和轮廓。实体倒角应在转动时产生连续高光。近景可见的分件与紧固件用实际几何实现，重复部件可用 `InstancedMesh`。参数化几何和离线建模导出的 GLB 都可接入。
- PBR 材质分别标定粗糙度与金属度。用粗糙度纹理、法线、AO 表现微表面，再切换白模、法线和线框排查拓扑、硬边和反面。透明体按实际壁厚建内外表面，设置相应 IOR。液面按尺度制作弯月面，并检查深度冲突。
- 校核印字与刻度的纹素密度。世界空间文字可用异步就绪的字体绘制 Canvas 2D 图集，再用字形实例渲染。大幅文字贴图可按镜头需要使用 2K 或 4K。交付近景时在目标分辨率逐帧审看。
- 检视自己的模型时，将 GLB 放在开发工程的 `public/models/`，或静态站点对应的 `models/`。在检视台 URL 后加 `?model=../../models/文件名.glb`。glTF 的外部纹理、缓冲区必须保留相对目录。Draco 解码器来自锁定的 Three.js 依赖。Vite 识别 `.ktx2`、`.hdr` 等资源扩展，若材质使用 KTX2，还需自行接入对应加载器和转码器。

## 场景接口

每个候选导出一个默认场景定义。`id` 在总装中唯一，`title` 显示在工具界面中，`beats` 至少有一拍。`beats[i].dur` 与 `hold` 都以秒计，分别控制动画阶段和自动播放的停留时长。`notes` 可为空数组。`enterWith` 可选 `fade`、`portal`、`portal-out`、`fold`、`wash`、`tear` 或 `split`。

| 接口 | 约定 |
| --- | --- |
| `create(ctx)` | 返回该场景独立的实例，取得共享图形、文字、音频、转场、快照和缓动函数 |
| `async init()` | 加载资源并创建几何或渲染目标。需要字体时先 `await ctx.text.loadFonts(...)`，默认采用本机字体。指定字体应另行检查加载结果 |
| `enter()` | 重置交互状态。预热、直接定位和再次进入都会调用 |
| `pointer(type, nx, ny, s)` | 坐标范围为 −1 到 1。按下命中时返回 `true` 以独占拖动，普通移动仍可驱动视差 |
| `update(s)` | 从 `s.p[i]`、`s._since[i]`、`s.k(i, start, end, ease)`、`s.sceneTime` 和指针位置计算姿态 |
| `render(target, s)` | 渲染到指定离屏缓冲，按该缓冲尺寸设置视口和相机宽高比。引擎负责最终上屏 |
| `resize()` | 普通播放器调整尺寸时更新场景自己的布局 |

场景动画应从指定时间求值。比较两个版本时给出同一 `go` 参数和指针位置，可避免每帧累加造成的差异。普通 URL 中的 `#场景ID-2` 表示第二拍。无头 API 的拍索引从 0 开始。

## 运行时检查

| 检查项 | 观察和复核方法 |
| --- | --- |
| 预热与快照 | `warmAll()` 依次初始化、离屏绘制、抓取 640 × 360 快照并调用 `gl.finish()`。按 O 查看缩略图，场景也可按 `ctx.snapshots[id]` 取纹理 |
| 显存与高分屏 | 场景级动态 RT 以场景 ID 为 owner。`park` 将闲置缓冲缩到 2 × 2，当前幕和下一幕可激活。固定快照与核心缓冲常驻。检查 `getState().stats`。DPR 最高 2，总绘制像素预算为 2560 × 1600 |
| 颜色与转场 | 检查 HalfFloat 路径、设备支持的最多 4× MSAA、五级 Bloom、AgX/ACES 色调映射、色差、晕光、暗角、颗粒与末级抖动。过渡时前后两个场景分别画到 RT，分屏使用两个完整视图合成 |
| 交互和声音 | 测试独占拖拽、轻点、横滑、右键、键盘、备注、副屏和静音。普通页面的第一次键盘或指针手势解锁 Web Audio |
| 无头截帧 | 先设置浏览器视口再打开 `master/index.html?headless`。等待 `window.ready === true`，用 `window.__deck.list()` 列出场景、`go(id, beat, seconds)` 定位、`step(dt)` 推进并截图。检视台使用 `window.__inspector` |
| 现场性能 | 在目标设备和镜头分辨率实测帧率、显存、长时间切换与上下文丢失提示。默认绘制像素有上限，截图的 CSS 尺寸与实际 WebGL 缓冲尺寸应分别记录 |
| 交付 | 独立单元静帧可归档到 `outputs/acts/<单元>/<候选>/`，总装静帧归档到 `outputs/master/`。单个项目资产上限 100 MiB，可拆件或压缩。自动验收输出 PNG |
